# Símbolos astrológicos e alquímicos

Os 23 SVGs usam contornos dos glifos Unicode da família Noto, convertidos em paths.
Não dependem de fontes instaladas nem de apresentação como emoji no navegador.
Cada desenho preserva as proporções originais e ocupa até 48 unidades numa grade de 64.

- Noto Sans Symbols, peso 500: signos, planetas (exceto Sol) e elementos.
- Noto Sans Symbols 2: Sol (U+2609).
- Licenças SIL Open Font License acompanham estes arquivos.

Fontes originais:
https://github.com/google/fonts/tree/main/ofl/notosanssymbols
https://github.com/google/fonts/tree/main/ofl/notosanssymbols2

Referências de identificação dos caracteres:
https://www.unicode.org/charts/PDF/U2600.pdf
https://www.unicode.org/charts/PDF/U1F700.pdf

Para regenerar, instale fonttools e execute `scripts/generate-celestial-symbols.py`
passando a pasta com `NotoSansSymbols.ttf` e `NotoSansSymbols2-Regular.ttf`.
